# DeepSeek Harness 桌面客户端（DSH-Pet-Client v2.2.0）

**浏览器化版本**：对话界面不再有系统级独立窗口——用系统默认浏览器的 PWA 独立窗口打开
`http://127.0.0.1:3080` 使用；本程序（dsh_client_full.exe）只负责两件事：
**悬浮鲸鱼（提醒你干活进度）** 和 **托盘**（打开/切换/退出入口），开机自启常驻。

> 本版鲸鱼素材为**黑色鲸鱼**：exe 图标、托盘/悬浮窗、PWA 站点图标统一为黑鲸。

## 一、快速开始

### 前提：dsh web 已部署并运行（WSL 或本机）
- dsh web 跑在 `http://127.0.0.1:3080`（浏览器能打开即 OK；WSL 部署见项目 README「WSL 部署」）
- 若用 `dsh-web-token-sync` 插件，token 自动写入 exe 同目录 `dsh-web-token.txt`，首次打开浏览器免手动认证

### 启动
双击本目录 `dsh_client_full.exe` → 屏幕右上出现悬浮鲸鱼 + 系统托盘出现鲸鱼图标。
**第一次使用：托盘左键（或单击鲸鱼）→ 自动拉起已安装的 PWA 对话窗口**（没装 PWA 则回落到默认浏览器打开）。

> 建议：把 `http://127.0.0.1:3080` 安装成 PWA（浏览器地址栏右侧「安装」图标），
> 独立窗口没有地址栏、更清爽，鲸鱼也会**优先跟随 PWA 窗口**变色。

## 二、操作速查

| 操作 | 效果 |
|---|---|
| 悬浮鲸鱼/托盘 左键单击 | PWA 对话窗口 **呼出 ↔ 最小化** 切换（未开则拉起 PWA） |
| 悬浮鲸鱼 拖动 | 移动鲸鱼位置 |
| 悬浮鲸鱼/托盘 右键 | 菜单（见下） |
| 菜单「切换：完整模式（复制指令）」 | 弹窗显示 `dsh-mode.sh full` 并自动复制 → 到 WSL bash 运行即切回完整模式（含第三方插件/HUD/终端等） |
| 菜单「切换：纯净模式（复制指令）」 | 弹窗显示 `dsh-mode.sh clean` 并自动复制 → 到 WSL bash 运行即切纯净模式（仅官方界面 + token-sync；页面/插件出问题时应急用） |
| 菜单「显示宠物 / 隐藏宠物」 | 显示/隐藏悬浮鲸鱼 |
| 菜单「退出」 | 完全退出本程序（鲸鱼与托盘消失，对话窗口一并关闭） |

**鲸鱼颜色含义**：
- **蓝** = 对话窗口可见（空闲待命）
- **黑** = 对话窗口收起 / 最小化
- **橙（心跳闪烁）** = 有提问或审批需要你处理
- **绿（常亮）** = 刚回复完成；把对话窗口切到前台看到回复后自动停（回到蓝）

> 同时开着浏览器标签页与 PWA 窗口时，鲸鱼**优先跟随 PWA 独立窗口**（按窗口有无地址栏区分）。

## 三、常见问题

- **浏览器打不开/连不上**：确认 dsh web 在 3080 运行（WSL：`sudo systemctl status dsh-web`；本机：重开 `dsh --profile web`）
- **页面提示未认证**：检查 exe 同目录 `dsh-web-token.txt` 是否为最新（dsh web 重启会换 token；装了 token-sync 插件则自动更新，重开 exe 或刷新页面即可）
- **页面异常（插件报错/白屏）**：托盘右键「切换：纯净模式」→ 复制指令到 WSL 运行 → 刷新浏览器即回纯净版；问题解决后「切换：完整模式」切回
- **鲸鱼不见了**：托盘右键「显示宠物」
- **想调界面字号**：用 dsh **官方设置**里的字号选项（本版已移除插件自带的界面字号，避免与官方功能冲突）
- **想退回带独立窗口的旧版**：下载 v2.1.x 版本使用（v2.2 与 v2.1 的 exe 可并存，互不影响）
